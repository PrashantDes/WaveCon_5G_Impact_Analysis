# WaveCon 5G Impact Analysis

This repository contains the deliverables for a WaveCon 5G impact analysis.

## Project files

| File | Description |
| --- | --- |
| [`WaveCon_5G_Impact_Analysis.pdf`](WaveCon_5G_Impact_Analysis.pdf) | Analysis report |
| [`WaveCon_5G_Impact_Analysis.pptx`](WaveCon_5G_Impact_Analysis.pptx) | Presentation |
| [`Wavecon_dashboard_analysis1.pbix`](Wavecon_dashboard_analysis1.pbix) | Interactive Power BI dashboard |

## Viewing the files

- Open the PDF with any PDF reader.
- Open the PowerPoint presentation with Microsoft PowerPoint or a compatible presentation app.
- Open the `.pbix` dashboard with Microsoft Power BI Desktop.
